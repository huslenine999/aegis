# Aegis — Engineering Handoff

Date: 2026-08-24
Branch: `main` (all changes described below are in the working tree — **not yet committed**)

## What Aegis is

Private, explainable release-security gates for small engineering teams. One
workflow: scan a repository → evaluate against a versioned policy → allow /
block / error decision with an explanation → durable findings with owners and
due dates → Ed25519-signed evidence manifests verifiable offline.

Ships three ways:

1. CLI (`aegis scan . --strict`) — exit codes 0=allow, 1=blocked, 2=error
2. GitHub Action (`action.yml`) — fail-closed PR gate, installs from
   `requirements.txt` (hash-pinned `uv export`)
3. Self-hosted workbench — FastAPI dashboard + PostgreSQL + Redis/RQ workers +
   notifier + Caddy (`docker-compose.yml`)

Author: Khuslen Gan-Ochir. Version 2.4.0. MIT.

### 7. Diff-aware gating (new feature)
PR scans gate on **newly introduced findings** instead of the whole tree.

Flow:
```
diff_aware scan → worker loads baseline = fingerprints already known for the
project (status != 'resolved') → policy_engine tags every raw report entry via
extract_findings (in-place, single fingerprint source of truth) →
strip_baseline_findings() removes tagged entries from the DECISION ONLY →
block iff a NEW finding crosses the severity threshold.
```

Key files: `app/findings.py` (`BASELINE_FINGERPRINT_KEY`,
`project_baseline_fingerprints`, `strip_baseline_findings`),
`policy_engine.run_policy_engine(baseline_fingerprints=...)`,
`app/scan_engine.ScanJobPayload.diff_aware`, worker wiring in
`app/worker.py`, enqueue wiring in `app/routes/project_routes.py`.

Semantics:
- Fail-closed: untagged entries always kept; baseline read failure gates on everything.
- Evidence artifacts stay unfiltered; only the verdict is diff-aware. ALLOWED
  reasons state how many pre-existing findings were excluded.
- Activation: automatic for GitHub PR-triggered scans; opt-in via API body
  `{"diff_aware": true}`; CLI unchanged (no project history).
- Resolved-then-reintroduced findings block again for exactly one scan, then
  re-enter baseline. Deliberate.

Tests: `tests/test_diff_aware_gating.py`.

## Environment gotchas

- macOS/zsh; Makefile recipes use `/bin/sh` (no process substitution).
- `uv export` writes its own output path into the file header — never
  byte-compare two exports from different paths (see `lock-check` for the
  workaround).
- `enrich_finding` copies whole issue dicts; `aegis_fingerprint` is popped
  there deliberately so the key never leaks into HTML/SARIF reports.
- Root `egg-info/` is regenerable; its absence can make
  `get_package_version()` return an older installed version until you reinstall.

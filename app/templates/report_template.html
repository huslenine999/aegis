How to read this report

Automated scanners checked the source code and its dependencies. If a scanner finds a blocking issue, the release gate stops the deployment until the issue is fixed or formally accepted.

The risk index is a relative severity signal derived from the findings. It is not a probability of exploitation and does not override the release decision.

CodeQL paths and signature matches are leads for review, not proof of an exploit or malware.
